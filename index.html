What this calculator does

This tool checks whether a set of decimal odds across 2, 3 or 4 mutually exclusive outcomes contains an arbitrage. It calculates the implied probabilities (1/odds), sums those probabilities, and — if the sum < 1 — shows a stake split that (in theory) returns your capital plus a guaranteed small profit regardless of which outcome wins.

Examples

  • 2-way (Tennis/Basketball): Player A 1.95 vs Player B 2.05 — use 2-way mode.
  • 3-way (Football 1X2): Home 2.10 — Draw 3.40 — Away 3.60.
    If 1/2.10 + 1/3.40 + 1/3.60 < 1, you can split stake across the three bets to lock profit.
  • 4-way (experimental): Rare markets with four mutually exclusive outcomes (e.g. some set-score markets). These are usually very tight.

Caveats: Execution risk, stake limits, commission, voided markets (retirements / abandoned matches) and price movement can all break an arb in practice. Always verify settlement rules & max stakes at each bookmaker.
